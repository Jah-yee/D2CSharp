# UserCode

This directory contains the working C# versions of the Delphi files from:

```text
Source/UserCode
```

After conversion, files from `TargetGenerated/UserCode` are copied here. Previously preserved manual corrections from `TargetReworked/UserCode` can then be restored.

Manual corrections should be made in this directory rather than in `TargetGenerated/UserCode`.

Both the test files and the UserCode files in the working target tree are formatted by the formatting projects.

UserCode files are intended for local use only and are ignored by Git.
