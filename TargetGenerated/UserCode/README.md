# UserCode

This directory contains the unmodified C# output generated from Delphi files in:

```text
Source/UserCode
```

The files are generated by D2CSharp and may be overwritten whenever the conversion is run.

Do not manually edit generated files here. If a generated file needs changes in order to compile or work correctly, make those changes in:

```text
TargetWorking/UserCode
```

The comparison between `TargetGenerated/UserCode` and `TargetWorking/UserCode` can then be used to identify required manual corrections or possible converter improvements.

UserCode files are intended for local use only and are ignored by Git.
