## Generated vs. manually corrected tests

The following WinMerge overview shows the comparison between
TargetWorking/Tests and TargetGenerated/Tests as it appeared at the time of the
repository's first public release.

Identical files required no manual changes at that time; highlighted files
contained manual corrections.

The current comparison has changed as development has continued. The image
is therefore a historical snapshot of the initial repository state and does
not represent the current number of differences between generated and working
files.
